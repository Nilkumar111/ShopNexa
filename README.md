# ShopNexa V2 upgrade

This upgrade preserves the existing `shopnexa.db` when copied over the existing project folder.

New: supplier dashboard shows customer orders for that supplier and supplier can update Processing/Shipped/Delivered; product detail pages and image URLs; improved store UI.

IMPORTANT: Back up your existing folder first. Replace app.py, templates and static only. Do NOT delete shopnexa.db.

Run: `python app.py`
